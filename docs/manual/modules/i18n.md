# Textes (i18n) — `ART_UI_TEXTS`

## À quoi ça sert
Tous les textes que le framework affiche lui-même (« -- Choisir -- », « Vrai/Faux », « Glissez-déposez vos fichiers ici », « Filtrer la colonne X »…) sont surchargeables : traduction, vocabulaire métier.

## Démarrage rapide
```ts
provideArtUiTexts({
  select: { choose: '-- Select --' },
  boolean: { yes: 'Yes', no: 'No' },
  file: { dropHere: 'Drop files here', browse: 'Browse' },
  list: { filterColumn: (c) => `Filter column ${c}` },
})
```
La fusion est **partielle** : seules les clés fournies sont remplacées.

## Groupes de textes
| Groupe | Contenu |
|---|---|
| `select` | `choose`, `add` |
| `boolean` | `yes`, `no` |
| `interval` | `min`, `max` |
| `validating`, `search` | Libellés de validation asynchrone et de recherche |
| `info` | `show` (nom accessible du bouton ⓘ) |
| `secret` | `show`, `hide`, `copy`, `copied`, `copyFailed`, `empty` |
| `color` | `open`, `hex`, `rgb`, `hsl`, `palette`, `preview`, `apply`, `close`, `hue`, `saturation`, `alpha`, `invalid`, `none` |
| `file` | `dropHere`, `browse`, `remove`, `uploading`, `uploaded`, `retry`, + **fonctions** `tooMany(max)`, `tooLarge(nom, taille)`, `badType(nom, types)`, `uploadFailed(nom)`, `selected(n)`, `progress(n)` |
| `modal` | `close` |
| `form` | `invalid` (toast du formulaire invalide) |
| `list` | `filterColumn(col)`, `sortBy(col)`, `apply`, `clear`, `clickToFilter`, `noData` |

Les textes de **votre** contenu (labels de champs, titres de colonnes) viennent de vos configurations, pas d'ici. Les messages d'erreur HTTP se configurent dans `provideArtApi({ statusMessages })` ; ceux du toaster dans `provideToaster({ titles, closeLabel })`.

## Lire les textes dans un composant à vous
```ts
protected readonly texts = inject(ART_UI_TEXTS);   // texts.select.choose
```
